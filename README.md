# Poks — preprod (Kaspa testnet-10)

Poker heads-up décentralisé sur Kaspa : la table est un covenant (coffre) sur la blockchain, les cartes sont
mélangées et chiffrées par les deux joueurs (mental poker). **Réseau de test uniquement, argent fictif.**

Ce dépôt ne contient que l'application compilée (site statique servi par GitHub Pages).
